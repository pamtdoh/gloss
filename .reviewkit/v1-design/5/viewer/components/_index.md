# The viewer is built from well-tested components, themed as itself

Interactive surfaces come from proven primitives — radix-ui, the cmdk
palette, lucide icons — running on React 19 and compiled with
Tailwind's standalone CLI, dressed in ReviewKit's own Ink & Amber
design-token layer. Only surfaces with no well-tested equivalent stay
hand-rolled (the fact tree, the toast, the composer). Each child fact
describes one component for individual review.
