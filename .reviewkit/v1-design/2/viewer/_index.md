# The viewer is a rich review surface, thin only on integration

A Preact single page served by the session: nested tree navigation with
change badges (directories open onto their `_index.md` plus a table of
child facts for bulk decisions), a ⌘K palette for search and commands, a
`?` shortcut overlay generated from the live key table, seen-tracking
with a progress readout (browser-local only), quote-anchored highlights
with fuzzy re-anchoring, and edit/delete/reply on every item. It stays
humans-only: no creation forms, no agent progress, no agent access to
its API.
