# The header compresses to what a thumb needs

Below 860px the title yields to the hamburger; the header shows the
page position ("12/31") because sequential readers care where they are
— the seen count lives in the drawer instead. The snapshot picker
compacts to "S9", and opening any non-latest snapshot raises a slim
amber banner under the header — "Viewing snapshot 7 — latest is 9 ·
Switch" — that jumps back to latest in one tap. The question pill
becomes an icon with a count; Finish review shortens to "Finish" —
responsive text, never truncation.
