# The tree scopes to All | Changed | Raised

The scope shares one line with the search input: a compact chip at the
row's end reading the current scope and its count ("All 41", "Changed
12"), opening a three-option menu with per-scope counts. When the
scope isn't All the chip tints accent — the active-filter signal
GitHub retrofitted in 2025. All is the whole snapshot; Changed is what
moved since the previous snapshot, deletions included; Raised is what
carries your comments and questions. `d` cycles the scope, the palette
names all three, and a snapshot switch resets to All — like the text
filter, so a fresh snapshot never starts with facts silently hidden.
