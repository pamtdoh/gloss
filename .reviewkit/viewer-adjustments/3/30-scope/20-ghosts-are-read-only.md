# A ghost is evidence, not a review target

A removed fact renders struck-through in the tree with a red ⊟ badge.
Opening it shows the full old content under a banner — "Removed in
snapshot N — shown as it was in snapshot N−1. Read-only." — with
images resolved from the snapshot it was deleted from. Nothing can be
done to it: no comments or questions, no seen mark, no bulk selection;
the panel says so. If a deletion was wrong, that conversation belongs
on a living fact or in the session thread — a sidecar for a file that
doesn't exist would break resolution-by-deletion.
