# One cmdk palette is both search and command surface

⌘K or `/` opens a cmdk dialog listing every fact (fuzzy-filtered, jump
on Enter) and every command — finish, approve, mark-all-seen, snapshot
switching, help. `?` opens a shortcut sheet generated from the same
declarative key table that drives dispatch, so help cannot drift from
reality. Overlays are radix Dialogs: real focus traps, focus restored
away from text fields so single-key shortcuts survive.
