# Selecting a directory shows its _index fact plus a child-fact table

The directory view renders the group's `_index.md` (when present), a
stats line (facts, undecided, open questions), and one row per child
fact: checkbox, title, badges, and hover/focus-revealed decision
buttons. Select-all plus row checkboxes feed a sticky bulk bar that
applies one decision to the whole selection, with an undo toast.
