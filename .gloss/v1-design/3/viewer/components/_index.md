# The viewer is built from owner-proven components, not hand-rolled ones

Interactive surfaces come from the component layer already reviewed in
leetcoach: radix-ui primitives, the cmdk palette, lucide icons, and its
design-token architecture, running on React 19 and compiled with
Tailwind's standalone CLI. Only surfaces with no well-tested equivalent
stay hand-rolled (the fact tree, the toast, the composer). Each child
fact describes one component for individual review.
