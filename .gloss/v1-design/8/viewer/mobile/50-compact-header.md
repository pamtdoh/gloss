# The header compresses to what a thumb needs

Below 860px the title yields to the hamburger; the header shows the
page position ("12/31") because sequential readers care where they are
— the seen count lives in the drawer instead. The snapshot picker
compacts to "S7", the question pill to an icon with a count, Finish
review to "Finish" — via responsive text, not truncation. On touch,
hover-revealed controls are always visible instead, because there is
no hover.
