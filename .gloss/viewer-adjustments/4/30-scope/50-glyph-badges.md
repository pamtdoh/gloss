# Change badges are glyphs in the tree, words where there's room

The tree's `changed` / `new` word chips became 14px glyph squares —
amber dot for changed, green plus for new, red minus for removed, each
with a tooltip — buying back ~45px of fact-name width in a 300px
column, the same trade GitHub and GitLab both make. The words survive
where width is cheap: the breadcrumb above the fact and the directory
table's badge column.
